🔌 API INTEGRATION
==================

ENDPOINTS USED

Authentication
  POST /auth/login           → User login
  POST /auth/logout          → User logout
  POST /auth/refresh         → Token refresh

Alumni Data
  GET  /alumni/{id}          → Get profile
  POST /alumni/engagement    → Record engagement
  POST /alumni/donation      → Record donation
  POST /alumni/forecast      → Generate forecast
  GET  /alumni/insights      → GenAI insights

Request Flow:
  1. User action in component
  2. Axios call with auth token
  3. Backend processes request
  4. Response updates component state
  5. UI re-renders with new data

📞 SUPPORT
==========

TROUBLESHOOTING

Port 3000 in use?
  → PORT=3001 npm start

API not connecting?
  → Check .env REACT_APP_API_URL
  → Verify backend running
  → Check browser console

Dependencies error?
  → rm -rf node_modules
  → npm clean cache --force
  → npm install

Blank page after login?
  → Check console (F12)
  → Verify backend API working
  → Check localStorage cookies
